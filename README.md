# 爷爷的厨房 🍳

一款专为家庭点餐场景设计的微信小程序。家人在手机上选菜、告诉爷爷今天想吃什么，爷爷在后台接单、标记完成；家人还能为做好的菜留下评价，分享温馨时刻照片，记录家庭的饮食记忆。

---

## 功能特性

### 家人端（普通用户）
- **点菜** — 按分类浏览菜单，支持自定义菜品，一键加入今日心愿单
- **菜单计划** — 按周规划每天想吃的菜，加菜时支持历史候选列表快速选择
- **菜品评价** — 对爷爷做好的菜打标签（夯爆了 / 偏咸了……）并留言
- **温馨时刻** — 发布带照片的家庭动态，首页自动轮播近期时刻
- **时间线** — 查看历史点菜记录，按周分组回忆

### 爷爷端（管理端）
- **今日订单** — 查看家人今天点了哪些菜、每道菜数量
- **标记完成** — 逐道或一键全部标记已做完
- **菜品评价汇总** — 查看每道菜收到的标签和留言

### 身份系统
- 区分「爷爷」和「家人」两种身份，家人可设置名字和头像
- 本地持久化，下次打开自动恢复身份

## 云数据库集合

| 集合名 | 用途 |
|--------|------|
| `orders` | 点菜订单（每笔含菜品列表、下单人、时间） |
| `done_dishes` | 爷爷标记已完成的菜品 |
| `dish_reviews` | 菜品评价（标签 + 留言） |
| `moments` | 家庭温馨时刻（照片 + 文字 + 点赞评论） |
| `weekly_menu` | 每周菜单计划 |

## 本地开发

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 克隆本仓库，用微信开发者工具打开项目根目录
3. 在 `project.config.json` 中填入你的 AppID
4. 开通微信云开发，在 `app.js` 中更新 `env` 为你的云环境 ID
5. 在云控制台创建上述 5 个数据库集合
6. 上传部署 `cloudfunctions/notify` 云函数

## 设计理念

这不是一个外卖 App，而是一个**家人之间的小小仪式**。爷爷知道今天谁想吃什么，家人知道爷爷在厨房里为他们忙碌——一道菜，一条留言，连接的是家的温度。
